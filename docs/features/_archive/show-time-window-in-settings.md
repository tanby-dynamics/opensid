# Show Time Window in Settings Tile Table

## Summary

In the dashboard settings table, the TILE column should include the configured time window as a third segment of the label. For example, a tile that currently shows "Savings — Balance over time" should instead show "Savings — Balance over time — Last 12 months".

## Detailed description

The dashboard settings table lists each configured tile with a label generated by `tileLabel()` in `DashboardSection.tsx`. Currently that function produces:

- `transactions` tiles: `"<Account name>"` (e.g. "Savings")
- All other tiles: `"<Account name> — <Tile type label>"` (e.g. "Savings — Balance over time")

Three tile types carry a `time_window` field: `balance_over_time`, `totals_by_category`, and `income_vs_expense`. The `formatChartWindow()` utility in `chartWindow.ts` already converts raw window values (e.g. `"12m"`, `"30d"`, `"8w"`, `"all"`) into human-readable strings (e.g. `"Last 12 months"`, `"Last 30 days"`, `"Last 8 weeks"`, `"All time"`).

The two remaining tile types — `transactions` and `budget_progress` — have no `time_window`, so their labels are unchanged.

## User stories

- As a user configuring my dashboard, I want the tile table to show the time window alongside the tile type, so that I can distinguish between multiple tiles for the same account (e.g. two "Balance over time" tiles with different windows) at a glance.

## Key decisions

| Decision | Outcome |
|----------|---------|
| Separator style | Em-dash (`—`), consistent with existing label segments |
| Scope of change | Settings table only; no other surfaces affected |
| Tiles without a time window | Labels unchanged (`transactions` shows account name only; `budget_progress` shows account name + tile type) |
| Time window formatting | Reuse existing `formatChartWindow()` from `client/src/utils/chartWindow.ts` |

## Acceptance criteria

```gherkin
Feature: Time window displayed in settings tile table

  Scenario: Balance over time tile shows time window
    Given a "balance_over_time" tile with time_window "12m" for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings — Balance over time — Last 12 months"

  Scenario: Totals by category tile shows time window
    Given a "totals_by_category" tile with time_window "30d" for account "Checking"
    When I view the dashboard settings table
    Then the TILE column shows "Checking — Totals by category — Last 30 days"

  Scenario: Income vs expense tile shows time window
    Given an "income_vs_expense" tile with time_window "3m" for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings — Income vs Expense — Last 3 months"

  Scenario: Custom weeks time window is formatted correctly
    Given a "balance_over_time" tile with time_window "8w" for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings — Balance over time — Last 8 weeks"

  Scenario: All time window is formatted correctly
    Given a "totals_by_category" tile with time_window "all" for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings — Totals by category — All time"

  Scenario: Transactions tile is unaffected
    Given a "transactions" tile for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings"

  Scenario: Budget progress tile is unaffected
    Given a "budget_progress" tile for account "Savings"
    When I view the dashboard settings table
    Then the TILE column shows "Savings — Budget Progress"
```

## Manual test steps

1. Open the app and navigate to Settings.
2. On the Dashboard tab, confirm there is at least one "Balance over time" tile configured. If not, add one (select any account, choose "Balance over time", pick a time window such as "Last 12 months").
3. In the tile table, verify the TILE column for that tile reads `"<Account> — Balance over time — Last 12 months"` (or whatever window was selected).
4. Add a second "Balance over time" tile for the same account with a different time window (e.g. "Last 30 days"). Verify the table now shows two distinct labels for that account.
5. Confirm that any "Transactions" tiles still show only the account name with no time window suffix.
6. Confirm that any "Budget Progress" tiles show `"<Account> — Budget Progress"` with no time window suffix.
