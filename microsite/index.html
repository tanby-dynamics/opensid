Self-hosting

Up in three steps

1

Create your docker-compose.yml

Copy this into a new directory on your server:

services:
  opensid:
    image: ghcr.io/tanby-dynamics/opensid:latest
    ports:
      - "3000:3000"
    volumes:
      - ./data:/data
    env_file:
      - .env
    restart: unless-stopped
2

Create .env

Configure your environment - adjust CORS_ORIGIN to match your domain:

# SQLite path inside the container
DATABASE_PATH=/data/opensid.db

# Restrict to your origin, or use * for open
CORS_ORIGIN=https://opensid.example.com
3

Start the container

Create the data directory and bring the stack up:

$ mkdir data
$ docker compose up -d

OpenSid will be available at http://localhost:3000.

↓

Updates

Pull the latest image and restart:

$ docker compose pull
$ docker compose up -d

Images are published for linux/amd64 and linux/arm64.
